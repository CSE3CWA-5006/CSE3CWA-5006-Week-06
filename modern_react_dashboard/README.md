# Modern React Dashboard

This teaching demo shows how a React interface can grow beyond a simple form and table.

It demonstrates:

- layout components
- reusable UI components
- feature components
- controlled search and filter state
- selected item state
- loading, error, empty and success states
- a custom hook for data loading
- responsive layout for desktop, tablet and mobile

## Run on Ubuntu

```bash
cd modern_react_dashboard
npm install
npm run dev
```

Open `http://localhost:5173`.
